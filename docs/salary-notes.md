# 如何阅读岗位薪资

页面保留招聘方的薪资标注。月薪以k表示千元/月，日薪单独列示；“月薪×标注月数”只是算术折算，不代表固定年薪、股权收益或奖金保证。

比较之前先划分实习、明确届别校招、资格待确认的正式岗、有经验社招。再看城市、岗位内容、学历、经验和薪资结构。高级岗位上限不能直接用于推算新人的学习回报。

样本分析页只对明确2027届的正式月薪作分组观察，并报告样本数。少于5个样本的方向不展示中位数；即使样本数较大，也不能排除公司、业务、年资和采集方式的影响。

这个项目提供探索和比较工具，不给出“某方向对所有人收益最高”的保证。学习路线的选择仍应结合已有基础、可投入时间、目标岗位与真实面试反馈。
