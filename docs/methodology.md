# 样本与统计口径

## 来源与范围

来源为猎聘公开招聘页面的定向观察，快照日期2026-11-16。初始观察包括嵌入式开发校招推荐，以及全国嵌入式软件类别下Linux、RTOS、runtime关键词的可见结果。Linux分段观察，RTOS前15个可见列表页，runtime前10页并复查跳过项。没有证明已覆盖全站或全部搜索结果。

初始有效记录231条，按公司、标题、城市及去掉截止日期后的正文精确去重得到218个岗位。重复组优先选择已逐页核对的记录；该步骤发生在生成公开摘要之前。近似文案、不同发布方或不同职位标题仍可能对应同一招聘需求。原始观察中184条曾逐页核对详情，但公开集不发布界面转储及完整原文。

## 公开边界

公开JSON只保存公司、岗位、城市、薪资、学历/经验、届别线索、方向、技能标签和整理摘要。摘要是字段整理，不能冒充招聘方完整要求。原始长文、联系人、设备、账户、研究或个人项目资料均不属于公开集。

## 可复算与不可复算

`scripts/build_data.py`只读取公开JSON，可重新计算城市、方向、技能和同口径薪资统计。原始观察及文本去重证据未公开，因此公开包不能完整重演采集过程，也不能证明平台覆盖率。技能标签及方向属于初步整理，可能存在归类误差。

## 统计定义

- 城市、方向：每个公开岗位计一次。
- 技能：每个岗位内同一标签最多计一次，不同标签可同时命中。
- 校招薪资：仅含明确2027届、非实习、非有经验岗位的月薪标注；先求区间中点，再求组内中位数。
- 每组薪资样本少于5个时，不展示中位数。
- 实习日薪与正式月薪不相互换算；未写薪资月数时不推定12薪。
- 广告区间中点的中位数不等于实际录用工资中位数。
- 届别判断排除截止日期，兼容“27 届”等空格写法；平台“学生可投”不自动等于应届生符合全部要求。

## 局限

定向关键词偏向系统软件与芯片方向，页数不相等，推荐流与重复发布会影响结果。这些数量不能用于推断全市场规模、城市真实机会份额、某方向因果薪资优势，或个人录用概率。岗位原始状态和薪资应在招聘平台重新核对。
