# 从岗位技能线索到八周学习示例

这是一份面向系统软件入门者的通用示例。样本提供技能需求线索，先后顺序结合工程先修关系，由人工整理；它不是统计模型推出的最优课程，也不是取得实习或高薪的保证。

| 阶段 | 学习主题 | 可检查的交付 |
|---|---|---|
| 第1周 | C类型、指针、数组、结构体、内存与字节序 | 小数组处理程序，能解释类型范围和边界输入 |
| 第2周 | C++基础、构建工具、Git、GDB、文件IO | 一个有长度与版本校验的二进制帧解析器 |
| 第3周 | Linux进程/线程、TCP/UDP、短读短写、超时 | 使用模拟数据的采集与回放服务 |
| 第4周 | 有界队列、同步互斥、背压、错误可见性 | 慢消费者、断线、坏帧等故障场景及处理记录 |
| 第5周 | 调试与性能分析 | 可重复的GDB定位记录、吞吐/延迟/资源占用测量 |
| 第6周 | 根据目标岗位选择Linux/BSP或MCU/RTOS | 一个边界明确的设备接口/外设练习，说明硬件与软件职责 |
| 第7周 | 对照目标岗位补缺口 | 三个能讲清的案例：现象、假设、证据、修改、复测 |
| 第8周 | 整理工程交付与表达 | 可复现的仓库、接口说明、演示和技术复盘 |

## 三条可选分支

- Linux/BSP：启动链、设备树、用户态/内核态接口、驱动模型与系统调试。
- MCU/RTOS：中断、定时器、外设、同步与实时调度。
- 芯片Runtime/Driver：在系统基础之上理解设备队列、Host–Device内存、异构调度和性能剖析；算子与硬件架构按岗位补充。

## 可复用的通用项目题目

“面向设备数据的采集与回放软件”：使用确定性模拟输入或公开测试数据，完成有版本的帧格式、错误检测、有界队列、网络交付及回放。为超时、断线、慢消费者和异常输入写出验证方法。它是教学示例，不依赖任何个人课题、私有代码、特定板卡或真实射频设备。

学习时以能解释、调试、修改和验证为标准。AI辅助工具可以帮助阅读与定位，但应理解生成代码、检查边界并亲自验证结果。课程进度应根据已有基础与真实反馈调整。
